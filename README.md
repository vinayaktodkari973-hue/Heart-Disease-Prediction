Heart Disease Prediction Using Logistic Regression

Project Overview

This project focuses on predicting the presence of heart disease using Machine Learning.

Logistic Regression is used as the classification algorithm to analyze patient-related features and predict whether heart disease is present.

This project was developed as part of my journey in learning Supervised Machine Learning.

Objective

To build a classification model that predicts heart disease based on input medical attributes.

Dataset

The project uses a heart disease dataset containing medical attributes and a target variable.

0 – No heart disease

1 – Heart disease present

Technologies Used

Python

NumPy

Pandas

Scikit-learn

Machine Learning Algorithm

Logistic Regression

Logistic Regression is a supervised classification algorithm used to predict categorical outcomes.

Model Development

The following steps were performed:

Imported the dataset.

Separated input features and target variable.

Split the dataset into training and testing sets.

Trained the Logistic Regression model.

Generated predictions.

Evaluated model performance.
